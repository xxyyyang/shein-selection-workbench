# 主图点击率分析（方法记录）

> 这一轮用的是**平台真实点击率**做标签，不是推测。
> 数据来源：SPU2.0 诊断列表（后台截图）+ 商品明细（后台截图）+ 主图 CDN 直链。
> 分析日期：2026-10-09
>
> ⚠️ **本文件已脱敏**：原始版本含真实货号、曝光量、点击率、转化率与订单数，
> 属于店铺经营数据，**不随代码公开**。本文件只保留分析方法和结论方向。

---

## 一、先说结论

**瓶颈是「点击率」，不是「平台审美审核」。**

在拿到真实点击率数据之前，整个项目一直在找"平台审美规律"——
但真实数据显示的是另一件事：**商品已经上架、平台也在给流量**。

所以问题不是"过不了审"，而是 **"顾客看到了，但不点进来"**。

| 维度 | 真实数据反映的情况 |
|---|---|
| 曝光 | 平台确实在给流量（7 天内有一批商品拿到了曝光）|
| 点击率 | **整体低于同类目常规水平** |
| 转化 | 曝光→订单的转化数量很低 |
| 排列 | 少数商品拿到了绝大部分曝光，多数商品曝光接近于零 |

## 二、数据结构（已脱敏）

原始诊断表的结构是这样，**这是分析的关键**——它把三件事分开了：

| 字段 | 含义 | 为什么重要 |
|---|---|---|
| 货号 | 商品编号 | 用于和主图、图案一一对应 |
| 曝光 UV | 有多少人看到了 | 判断平台是否在给流量 |
| 销量 | 成交数量 | 判断转化能力 |
| **点击率** | 看到→点进来的比例 | **这是这一轮的核心指标** |
| 转化率 | 点进来→下单的比例 | 区分"图的问题"还是"价格/详情的问题" |
| 商品名 | 图案主题 | 用于按题材分组对比 |

> **为什么这个结构重要**：它让"没流量""有流量但没人点""有人点但不买"
> 变成三种**可以分开诊断**的状态。而在之前 15 轮里，这三种被混成了一个"失败组"。

## 三、逐商品瓶颈诊断（方法）

拿到上面五个字段之后，可以给每个商品打一个**瓶颈标签**，而不是笼统地说"图不行"：

| 状态组合 | 瓶颈判断 | 该做什么 |
|---|---|---|
| 曝光高 + 点击率合格 + 有成交 | ✅ 有潜力 | 加大推广 |
| 曝光高 + 点击率合格 + 0 成交 | ⚠️ **转化问题**，不是图的问题 | 查价格 / 运费 / 评价 |
| 曝光高 + 点击率低 | ❌ **主图问题** | 换主图 |
| 曝光极低（接近 0） | ❌ **流量问题** | 查类目 / 标题关键词 / 是否被降权 |

> **这个分类是整个分析最有价值的部分**：
> 同样是"卖不动"，**换主图和查价格是两个完全不同的动作**。
> 之前混在一起，所以改了很多次图片都没效果。

## 四、主图对比发现的差异（重要，但样本小）

把多张真实主图下载下来逐一对比，发现一个明显模式：

> **毯子与背景的明暗反差 / 颜色距离，看起来和点击率相关。**

测量方法：对每张主图算两个量——
**明暗反差**（毯子区域与背景区域的亮度差）和
**颜色距离**（两者的色彩空间距离）。

**观察到的方向**：

| 主图类型 | 反差 | 点击率表现 |
|---|---|---|
| 深色毯挂深色墙前 | 高反差 | 相对较好 |
| 白底图案铺米色沙发 | 中等反差 | 相对较好 |
| 米黄/浅色毯铺浅色沙发 | 低反差 | 偏低 |
| 粉毯铺粉床 / 白毯铺白墙 | **最低反差** | **最差，其中两个零曝光** |

**相关系数**：明暗反差约 +0.44、颜色距离约 +0.43

> 具体数值与货号对应的明细表已移除，只保留方向性结论。

### ⚠️ 必须说明的局限

- **只有 6 个商品有可用点击率数据**，样本极小
- 相关系数**极不稳定**，只能当**方向性提示**，**不能当结论**
- 未排除混杂因素（价格、上架时间、推广力度、类目竞争）

## 五、给主图的具体修改方向

**如果采纳"提高反差"这个方向**（成本低，可验证）：

1. **同款图案，换深色或中性色背景** ——
   大量使用"浅色沙发 + 白墙"时，米黄色系毯子会和背景糊在一起
2. **毯子挂起来展示**，而不是叠放在沙发上
3. **优先改点击率最低的那一个**：白底图案配白墙，几乎看不见毯子轮廓
4. **避免"同色系搭配"**：粉毯配粉床是反差最低的组合

**验证方法**：
改 2~3 个商品的第 1 张主图，**其他条件不动**，观察 1~2 周的点击率变化。
**这是唯一能确认因果的办法。**

## 六、这次分析和之前 15 轮有什么不同

| | 之前 15 轮 | 这一轮 |
|---|---|---|
| **标签** | **猜的**（把"没卖动"当成了"被刷"）| **平台真实点击率** |
| 对比条件 | 时间不同、状态不同 | 同平台、同期、同样曝光机会 |
| 结论 | "平台审美规律"——没找到 | "点击率低"——有数据支撑 |
| 可执行性 | 改图片风格（不知道改什么）| 改主图，可 A/B 验证 |

**教训**：前 15 轮一直在**猜数据结构**，导致反复做错方向。
拿到真实数据（诊断列表 + 主图链接）之后，一次就定位到了问题。

> 这和本项目另外三个被推翻的结论是同一个根源：
> **在标签语义没确认清楚之前就开始分析。**
> 详见 [`项目现状梳理.md`](项目现状梳理.md)。

## 七、下一步（按价值排序）

1. **改点击率最低那个商品的主图**（改一张图成本极低）
2. **有成交的商品加大推广**（转化率不低，说明详情页没问题）
3. **点击率高但零成交的商品查转化**（价格 / 运费 / 评价问题）
4. **查零曝光商品**（类目、标题关键词、是否被降权）
5. **改完主图后等 1~2 周，用新的点击率数据验证"反差"假设**
