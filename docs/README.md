# SHEIN 选品工作台

一个跨境卖家的印花毛毯选品工具：**把档期、抓图、打标签、出标题串成一条流水线。**

主要解决三个具体问题：

1. **赶不上节点** —— 不知道什么时候该动手，等知道时海运已经来不及了
2. **抓到废图** —— 免费图搜抓回来的图 2/3 是带水印的侵权素材
3. **标签没法用** —— 让 AI 自由打标签，产出是一堆互相矛盾的词

---

## 三条核心逻辑

### 1. 档期 × 前置期倒推

不是"提醒你节日还有几天"，而是**"你只剩几天能下单"**：

```
美国 · 黑五          2026-11-27
  海运(45天) 最晚下单  2026-10-13   ← 就是今天
  空运(20天) 最晚下单  2026-11-07

沙特 · 开斋节         2027-03-09
  海运(45天) 最晚下单  2027-01-23
```

支持 **SA / GB / US** 三个市场，可扩展。

**踩对的坑**：

| 坑 | 处理 |
|---|---|
| 伊斯兰历（斋月每年提前 ~11 天） | `holidays` 库的阿拉伯语原文 + 中文对照表。实测 2027→2028 提前 11 天 |
| **复活节**（天文历法，不能用"第几个周几"表示） | Gauss/Anonymous Gregorian 算法，对照 2024–2029 标准答案 **6/6 全对** |
| **英国母亲节** | 复活节前第 4 个周日（**不是 5 月**）。= 复活节 − 21 天 |
| 跨年顺延 | 今天 10 月，正确显示明年的节点 |
| 行政假日混入 | 排除，否则"已错过"一堆假警报 |

### 2. 抓图自带三重过滤

| 过滤 | 实测 |
|---|---|
| **水印检测**（OCR + 归一化匹配） | 百度/必应 **68% 带水印**；亚马逊商品图 **0%** |
| **URL 归一化去重** | 亚马逊一张图 5 个尺寸版本 → 331 个链接去重到 60 |
| **感知哈希去重**（dHash） | 抓 39 张里 **30 张是近似重复** |

实测水印率对比（各抽 25 张）：

```
亚马逊      0 / 25   ( 0%)   ← 商品图，卖家自己拍的
自写爬虫    9 / 25   (36%)
百度/必应  17 / 25   (68%)   ← 素材站样图，商用侵权
```

**结论：免费图搜抓回来的图，三分之二是侵权素材站样图，不能直接用。**

### 3. 受控词表 —— AI 只能从人的词表里选

**反面教材**（让 VLM 自由打标签的真实产出）：

```python
['暖橙红','暖黄棕','大地色','莫兰迪暖','粉色系','复古做旧']   # 6 个互相矛盾
```

**改成受控词表后**：

```python
['暖橙红','蓝绿冷','多彩撞色']   # 3 个，各有所指
```

词表：**8 个维度 / 110 个标签**，可自行增删。
打标签时 AI 只能从词表里选，选到表外的会自动纠正或丢弃。

## 完整工作流

```
📅 档期页      看什么时候该做什么（三市场 + 海运/空运双截止）
      ↓ 一键带关键词
🌐 抓图页      亚马逊 / Target / 百度 / 必应
      ↓ 自动：URL 去重 → 感知哈希去重 → 水印过滤 → 打标签
      ↓ 打标签时顺手生成：标题字段 + SHEIN 三词库各 3 个候选
📁 存档页      按节日/批次浏览，组合标签筛选
      ↓ 单击选中 → 复制到"已选"文件夹（自动标已用）
📝 标题页      ① 用标签出标题（本地，不调 API）② 本地组合多版本
      ↓ 标题 + 上架填表字段（场合/风格/细化图案，精确匹配 SHEIN 词库）
      套 PS 模板 → 上架
```

### 多标签组合查询

**发现的问题**：以前每个标签单独搜，得到"纯南瓜图""纯幽灵图"，
**综合元素的图一张都搜不到**。

**修法**：生成组合查询，按**命中标签数**从多到少排：

```
 1. [4个标签] halloween pumpkin ghost bat     ← 最综合，优先抓
 2. [3个标签] pumpkin ghost bat
 3. [2个标签] halloween pumpkin
 ...
 8. [1个标签] pumpkin                          ← 单标签只兜底
```

### SHEIN 词库对齐

标题分两类字段，**不能混**：

| | 用途 | 例子 |
|---|---|---|
| 标题文本 | 好看、好搜 | 「秋季」「秋日温暖」 |
| **上架填表** | SHEIN 下拉框，**必须一字不差** | 「丰收节」「休闲-舒适极简」 |

词库里**没有"秋季"**，所以标题引领词用 `丰收节`。
词库里**没有"枫叶"**，所以细化图案填 `树叶图案`。
这些映射在代码里做，**AI 选错会自动纠正**。

```bash
pip install requests pillow holidays playwright icrawler
playwright install chromium      # 或用系统 Chrome（代码优先用 channel="chrome"）
```

**首次运行**：

```bash

python -m shein_scout doctor     # 环境体检
```

## 命令

**当前工作流**：

| 命令 | 作用 |
|---|---|
| `season` | 档期 × 选品联动（多市场 + 标签推荐 + 抓图关键词） |
| `patterncrawl` | 抓图 → 去重 → 滤水印 → 入库 |
| `tagctl` | 用受控词表打标签（顺手出标题字段 + 词库词） |
| `junk` | 扫描/清理废图（水印、重复、太小） |
| `titlegen` | 生成 SHEIN 标题 + 上架标签 |
| `library` | 图案库：搜索 / 标记已用 / 导出 |
| `init` / `doctor` | 初始化目录 / 环境体检 |

## 可迁移设计

所有路径从 `配置.json` 或环境变量读，**不写死在代码里**：

```
DSH_SCOUT_DATA    数据根目录
DSH_SCOUT_PROJ    项目根目录
DSH_PYTHON        Python 解释器
DSH_SHEIN_VOCAB   SHEIN 词库目录
```

**迁移到新机器**：拷一个文件夹 → 双击 → 程序自动创建缺失的目录结构。

`paths.hardcoded_report()` 会扫出所有硬编码路径（当前 **0 处**）。

## 我们试过但走不通的路（负结果记录）

这部分可能比功能列表更有价值。

| 假设 | 结论 | 证据 |
|---|---|---|
| 「低饱和度更容易过审」 | ❌ **否证** | 朋友过审图饱和度 0.359，落在"被刷组"区间内。**时间混淆**：成功组 06-27~08-04，被刷组 08-04~09-07，**完全不重叠** |
| 「图片风格是被刷主因」 | ❌ **否证** | 260 张图 VLM 打标签：摆放方式/构图角度/场景类型/背景/毯面材质/有人出镜 **两组完全一致** |
| 「尺寸不合规」 | ❌ **否证** | 341 张 mockup 里 272 张（80%）符合官方规范 |
| 「按图像特征训练过审画像」 | ❌ **否证** | 130+ 特征工程 + 过拟合诊断，最后发现**图片不是瓶颈** |

**真正的瓶颈是主题和时机**：

| 对比 | 本店 | 同类爆款 |
|---|---|---|
| 主题 | 万圣节（窗口 ~2 周） | 秋季通用（窗口 ~3 个月） |
| 最高曝光 | 1,381 | **7,006（5 倍）** |

## 已知限制

| 限制 | 说明 |
|---|---|
| **沙特标签无数据支撑** | 斋月→灯笼/月亮/清真寺 是按常识写的，**没有销售数据验证** |
| **备货前置期是占位值** | 海运 45 天 / 空运 20 天是默认值，需按实际情况调整 |
| **标题工艺词规则是推测** | 部分来自经验，未系统验证 |
| **只支持 Amazon / Target** | Walmart 有验证码、eBay/Wayfair/SHEIN 有反爬、Etsy 网络不通 |
| **AI 标签准确率未评估** | 没做过系统的人工抽检对比 |
| **前期模块仍在仓库** | 4,293 行实验代码被 import 链挂着，已加 `【归档】` 标注 |
