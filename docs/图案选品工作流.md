# 图案选品工作流

> 按你的思路做的：**爬图 → AI 打标签 → 你点亮喜欢的标签 → 下次排序靠前**

## 为什么是这样设计的

你说过两句关键的话，决定了整个结构：

> **"第一是节日活动主题，第二是配色风格"**

> **"节日/主题这种必须在占大分量权重，或者我在爬图时候就会说明"**

**第二句点破了之前的谜**：我前面 15 轮一直在同一批万圣节图里找规律（饱和度、摆放、构图），
结论全部作废。原因是——

> **主题是「分区键」，不是「排序维度」。**
> 你不会拿万圣节的图跟圣诞节的图比"哪个好看"，它们是两批货。

所以结构是：

| 层 | 作用 | 怎么用 |
|---|---|---|
| **① 节日/主题** | **硬分区** | **爬图时用关键词指定**，同主题内才比审美 |
| **② 配色风格** | **主排序**（同主题内） | 点亮你喜欢的配色 |
| **③ 季节/画风/密度/元素** | 细排序 | 权重低，量大了再细分 |

**排序权重**（代码里的实际值，主题占大头）：

| 维度 | 权重 |
|---|---|
| 节日主题 | **×3.0** |
| 配色风格 | **×2.0** |
| 适用季节 | ×1.5 |
| 画风 / 图案密度 | ×1.0 |
| 画面元素 | ×0.8 |

## 四步走

### 第 1 步：爬图（同时说明主题）

```bash
# 主题写在关键词里 —— 这就是"硬分区"
python -m shein_scout patterncrawl "fall leaf pattern" --want 100 --tag
```

* `--tag` = 爬完自动调豆包打标签（**不加就不打，纯存图**）
* 图存在 `patterns/<批次>/<关键词>_<源>/`
* 图同时进**图案库**（`patterns/library.jsonl`）

### 第 2 步：AI 打标签

已经在第 1 步做了（`--tag`）。也可以事后补：

```bash
python -m shein_scout tag --unlabeled          # 只打还没标签的
python -m shein_scout tag --limit 20           # 先试 20 张看质量
```

**每张图打出来的是固定选项的标签**（不让 AI 自由发挥，这样标签才能统计、能加权）：

```json
{"节日主题": ["秋季感恩节", "花卉植物"],
 "配色风格": ["暖橙红", "低饱和素雅"],
 "图案密度": ["满版密铺"],
 "画风": ["手绘插画"],
 "画面元素": ["无"],
 "适用季节": ["秋季"]}
```

**标签取值表**（想改就改 `shein_scout/tagger.py` 顶部的 `THEME` / `COLOR` 等）：

| 维度 | 候选数 | 例子 |
|---|---|---|
| 节日主题 | 23 | 万圣节、秋季感恩节、圣诞节、动物宠物、花卉植物、几何抽象、格纹拼布… |
| 配色风格 | 15 | 暖橙红、大地色、莫兰迪冷、马卡龙粉、黑白灰、高饱和鲜艳、复古做旧… |
| 图案密度 | 5 | 满版密铺、大面积留白、单一大图案、小碎花… |
| 画风 | 8 | 写实、手绘插画、卡通可爱、水彩、线稿、拼布格子… |
| 画面元素 | 7 | 文字标语、边框花纹、格纹底、渐变… |
| 适用季节 | 5 | 秋季、冬季、春季、夏季、四季通用 |

### 第 3 步：点亮你喜欢的标签 ← **你提的核心交互**

```bash
python -m shein_scout tagpick
```

打开生成的 `runs/图案库/tagpick.html`，按维度列出所有标签，**每个标签后面标了有多少张图**。

| 操作 | 效果 |
|---|---|
| 点一下 | 喜欢（权重 ×1） |
| 再点一下 | 很喜欢（权重 ×2） |
| 第三下 | 取消 |

主题和配色维度**排在最前、左边有蓝条标记**，因为它们的排序权重最高。

点完 → 导出 → 应用：

```bash
python -m shein_scout tagapply <导出的json>
```

### 第 4 步：下次爬图自动靠前

再跑第 1 步时，会看到：

```
  按你点亮的标签排序：37/77 张命中你的偏好
  最符合你偏好的前 8 个:
     1. 命中 秋季感恩节/暖橙红/手绘插画  分 8.0  fall_leaf_pattern
     2. 命中 秋季感恩节/大地色            分 5.0  fall_leaf_pattern
     ...
```

打标签页面里的图也按这个分排序 —— **好图案集中在前面，你标起来更快**。

## 图案库

```bash
python -m shein_scout library                      # 生成图案库页面
python -m shein_scout library --export-good --copy-files   # 导出所有「好」的图案
```

图案库页面能：按标签/关键词/备注搜索、标记「已用」、导出变更。
改完点「导出变更」把 json 发我，我写回库。

## 命令速查

| 命令 | 作用 |
|---|---|
| `patterncrawl "关键词" --want 100 --tag` | 爬图 + AI 打标签 + 入库 + 生成打标签页 |
| `tag --unlabeled` | 给库里还没标签的图补标签 |
| `tagpick` | 生成标签点亮页（**选你的审美偏好**） |
| `tagapply <json>` | 应用点亮的标签 |
| `library` | 图案库页面：搜索 / 标记已用 / 导出 |
| `patternlabel <json>` | 导入逐张的 好/坏 标注（可选的补充） |
| `patternlearn` | 另一种学法：从逐张标注学特征模型（可选） |

## 已知限制

* **豆包接口会间歇 SSL 报错** —— 打标签有重试，但网络差时会失败几张，重跑 `tag --unlabeled` 补上
* **标签是 AI 判断，会有错** —— 比如把"蓝绿冷"看成"莫兰迪冷"。所以**你的点亮才是最终依据**
* **爬到的图质量参差** —— 有些是商品实拍而非纯图案，AI 也会照样打标签
* 每张图打标签约 **4 秒**，100 张约 7 分钟
